# Snapshot cleanup, 2026-10-12 (requested by the owner)

The full working-tree snapshots `checkpoint-1` … `checkpoint-27` were deleted, and the
compiled Lean build output (`.lake/`) was removed from `checkpoint-28`. `checkpoint-28`
otherwise remains (the checkpoint-29 publication scripts read
`checkpoint-28/SafeLearning/cmdp.html` and one checkpoint-28 log). `checkpoint-29` is untouched.

Before deletion, every non-`.lake` file in checkpoints 1–28 was hashed with `git hash-object`
and compared against all objects in `reports/book/publication-repo` (`git rev-list --objects --all`).
All but 182 files were present byte-for-byte in git history; those 182 (185 MB, mostly
`__pycache__` and `kernel-progress.json`) are preserved under `snapshot-residue-not-in-git/`
at their original relative paths. `.lake/` is rebuildable from the proof sources.
The `checkpoint-N-*.json` manifests/selections next to the snapshot folders are kept.

Going forward, please do not copy `.lake/` build output or earlier snapshots into new
checkpoint snapshots; each checkpoint was re-copying everything before it.
